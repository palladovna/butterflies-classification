#### Butterflies Classification — Image Classification Project

## Описание проекта

Этот проект посвящён задаче многоклассовой классификации изображений бабочек (100 классов).
Цель — сравнить несколько архитектур нейронных сетей и выбрать наиболее эффективную модель.

В проекте реализованы:

Custom AlexNet

ResNet18

VGG16

Каждая модель была обучена на одинаковом датасете и одинаковых условиях, что позволяет корректно сравнить результаты.

## Результаты

| Метрика       | AlexNet | ResNet18   | VGG16  |
| ------------- | ------- | ---------- | ------ |
| **Accuracy**  | 0.6520  | **0.9120** | 0.9100 |
| **Precision** | 0.6845  | **0.9306** | 0.9265 |
| **Recall**    | 0.6520  | **0.9120** | 0.9100 |
| **F1-score**  | 0.6369  | **0.9079** | 0.9084 |


## Выводы

* ResNet18 показала себя наилучшей моделью благодаря:

        устойчивости к разнообразию данных

        более глубокой архитектуре

        хорошей обобщающей способности

* VGG16 — стабильная модель, но тяжелее и медленнее ResNet

* Custom AlexNet — компактная, быстрая, но уступает по качеству (что логично, так как архитектура написана от руки и не pretrained)
